# 合同、订单、验收及发票列表样式统一

日期：2026-10-30

## 调整范围

- 统一五张列表：采购合同、采购订单、待收货验收、历史验收记录、发票付款。
- 固定关键列宽，名称、编号、供应商、运单和较长结论单行省略，悬停保留全文。名称与编号、承运商与运单、合同起止日期采用明确的双行层级，不任意折行。
- 金额和日期采用紧凑的等宽数字显示；正常演示金额 178000 元可以完整展示，超长金额仍可悬停查看。
- 右侧操作列固定，详情按钮统一宽度，多操作按钮保持同行。提交审批、复核、验收登记、去验收、去付款、处置复核等原入口及权限条件不变。
- 保留原有手机卡片，收紧长文本显示，不将整张宽表强塞进手机视口。桌面视窗不足时仅表格容器横向滚动，固定操作列可见。
- 共用 `lib/compact-list.ts` 样式常量，避免后续各业务列表分别修改按钮和表格间距。
