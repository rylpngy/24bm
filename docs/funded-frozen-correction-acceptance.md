# 专项资金冻结付款更正验收与交付

日期：2026-10-27。业务及固定构建提交：`18139ff897d38acd0d8904a6eef42493348e4bdd`。文档后续提交不改变业务产物。

本批 PR：[#145](https://github.com/rylpngy/24bid/pull/145)，基于尚未合并的 #144，不代表已更新原系统。

## 完成能力

- 历史冻结实付按每项原资金来源明确选择当前项目版本的回补来源，经独立 Flowable 审批后生效。
- 校验同部门、当前年度、已批准来源、现有项目资金版本、真实原付款分账及合并目标额度；审批时二次核验。
- 保留原付款，追加精确原年度/原来源/原版本的反向分账，以及当前计划的不可变责任恢复记录。有效已付基线通过已批准增量计算，不覆盖原基线或承接快照。
- 在审时保护专项付款、直接冲销、继续承接及采购执行归档；撤回、驳回、依据变化、容量不足不产生财务副作用。
- 表单明确必选来源，更正详情展示映射及真实审批；归档包含原实付、反向实付、来源及回补、审批人和历史承接依据。
- 数据库延迟完整性约束阻止仅记反向现金、不完整回补原来源等不一致状态。
- 旧版无专项资金的在审更正保持快照兼容。修正新开更正对话框重复使用旧提交键的问题，同一对话框网络重试仍保留原提交键。
