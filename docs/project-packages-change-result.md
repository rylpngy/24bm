| 兼容 | 原单执行按需固化基线，不回填/替换原需求或采购记录；默认预算预警保留 |

## 边界
分包下发仅接通询比与招标，不宣称商城/竞价已接入项目分包。已有订单不能失败重采；已生成需求的包不能直接取消。批准变更不能追溯改写已分包范围；跨年度结转及已执行包整体重构另行规划。
本地完整付款登记链不等于外部银行支付；客户SSO和外部供应链等仍待客户环境。本批不启用prod、不替换认证策略。
