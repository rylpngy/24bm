# 阶段三 Java 模式逐页联调清单

## 目标

这份清单用于阶段三第一轮收口：确认后台壳、三端菜单和核心页面在 Java 数据源下可以逐页打开。它不替代后端 API 冒烟测试，也不等同于第二轮表单和详情页开发完成。

通过这份清单后，才进入第二轮。

## 启动顺序

1. 启动 Java 后端：

```bash
cd backend-java
mvn clean spring-boot:run -Dspring-boot.run.profiles=local
```

2. 执行 Java API 主流程冒烟：

```bash
npm run java:smoke
```

3. 启动前端 Java 模式：

```bash
npm run dev:java
```

4. 使用普通浏览器或内置浏览器打开：

```text
http://localhost:3000/
```

## 通用验收信号

每个页面都要确认：

- 顶部数据源显示 Java 模式或 Java 后端连接状态。
- 页面没有 `加载失败`。
- 页面没有 `argument type mismatch`。
- 浏览器控制台没有 React runtime error。
- 页面没有横向溢出。
- 菜单切换后页面主体内容能稳定渲染，不出现空白页。

## 失败处理

如果任一页面出现问题：

1. 先确认 `npm run java:smoke` 是否通过。
2. 如果 API 冒烟失败，先修 Java 后端或种子数据。
3. 如果 API 冒烟通过但页面失败，检查 `services/procurementApiClient.ts` 的 Java 数据映射。
4. 如果页面只在某个菜单失败，优先补该页面的数据兼容和空态。
5. 修复后重新执行对应页面的浏览器验收，再跑 `npm test` 和 `npm run build`。

## 通过标准

可以进入第二轮的最低标准：

1. `npm run java:smoke` 通过。
2. `npm run dev:java` 下 `http://localhost:3000/` 可打开。
3. 三端逐页验收矩阵全部通过。
4. 页面无 `加载失败`、无 `argument type mismatch`、无 React runtime error、无横向溢出。
5. `npm test` 和 `npm run build` 通过。
