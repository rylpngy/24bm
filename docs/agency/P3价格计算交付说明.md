# P3第六项：冻结价格规则与十进制计算明细

2026年11月9日。新增独立价格规则及计算工作区，接续已交付的初次报价分层和谈判/磋商线下最后报价。实现价格项或价格比较明细，不代表综合汇总、确定排名、候选人推荐、有权结果确认或成交金额。未部署生产。

## 操作与规则边界

入口：“评审准备 → 独立评审任务 → 价格规则与计算明细”。仅冻结的组织人员或组长可访问，另需价格计算读取/管理权限；普通评审人员即使持通配权限仍不能访问。单一来源页面不展示该入口，服务端不允许冻结竞争性价格计算规则。

先分别填写原文和系统价格规则：价格来源、公式、绑定价格项、满分、结果保留位数、舍入方式及同价/同分后续处理依据。记录规则版本、适用依据和本轮已冻结定稿的原文定位。草稿支持版本校验及继续维护，显示逐项差异；存在差异、方式不符、权重不符或未明确人工核对时不能冻结。冻结快照绑定原评审轮次指纹和定稿版本，不可覆盖；修改规则须按异常程序另行组织。

本轮只支持两种固定计算方式，不执行脚本或自由表达式：

- 综合评分的独立价格分：`基准最低价 × 价格满分 ÷ 当前价格`。价格满分必须等于本轮已冻结商务价格项的权重，不在原100总权重上另加价格分。基准来自本次明确选择的有效输入集合，不配置平均价、异常价格剔除或其他推定基准。乘积不舍入，只在最后一次除法按0至6位及HALF_UP/HALF_EVEN/DOWN舍入。
- 非综合评分方法的独立价格比较：保留原十进制价格及最低值，不生成分值或重排对象。零价格可以保留；比例公式遇到零价格阻断，不除零、补价或自动剔除。单一来源不进行竞争性价格比较。

原始初次报价、已确认修正价、已确认政策评审价须明确选定其中一层；指定来源缺失或修正后政策价失效时不自动回退。谈判/磋商只读取本任务已逐家确认为有效的原始最后报价，未提交、逾期或排除对象不以首次报价补齐。最后报价的修正及政策调整尚未接入，不能将原始最后报价冒称政策评审价格。

## 计算、复核与历史

按顺序开放适用末阶段、相关独立意见全部提交且不存在待审更正后，从末阶段对象中明确选择计算范围；所选对象存在未通过审查时阻断。未纳入者必须逐家填写处理依据，并在确认时引用封存的脱敏范围及计算复核凭证。低于已锁定对象数量门槛时阻断，即使填写排除理由也不自动放宽门槛。这里的范围处理不自动恢复或终止评审，不替代正式异常处置。

预览列出基准最低价、输入价格、币种、来源记录及SHA256、精确分子、最终价格分、保留位数和舍入顺序。金额、分子、分值均按十进制字符串输出；后端使用BigDecimal，避免大金额浮点损失。输入币种须与采购包一致。

人工核对全部明细后确认，服务端在采购包事务锁下重新计算，校验规则和输入指纹及真实封存凭证字节，保存不可覆盖的计算快照。报价台账修订、最后报价处理、独立意见、更正或采购包有效状态变化，会使旧确认失效；页面保留已填写说明。历史显示是否需要重新复核，旧价格与计算结果保留。界面展示最近30次历史，每任务最多保留100次记录。

系统不回填、修改个人意见，也不把价格分与人工分值自动相加。绑定价格项用于核对权重，未来汇总仍须明确客观价格项与个人评分项的唯一来源，避免重复计分。当前同分依据只留存，不执行排序；不得把一份独立价格计算当作当前确定排名或推荐结果。
