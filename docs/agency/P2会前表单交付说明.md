# P2会前人员表单与签署回传

日期：2026年11月8日。本轮接续[参与台账批量导入](P2批量导入交付说明.md)，完成会前准备人员名单、四类打印表单、受限签署件上传及人工回传关联。代码仍在 `codex/24bm-agency` 隔离工作区，未部署生产，原24Bid工作区保持不变。

## 使用流程

进入已通过建档且没有待审重要变更的采购包，打开“采购执行工作台 → 会前准备”。除会前准备读写权限外，还须具备人员保密权限；生成、上传、下载另按附件权限控制。

1. 在“准备人员名单”维护姓名、单位、准备职责及维护原因。支持采购人代表、评审成员、组长、资格审查人员、符合性审查人员、项目组织人员、监督人员等准备职责。名单记录不创建系统账户，也不授予正式评审或评分权限。
2. 展开“生成打印表单”，选择人员和表单类型，核对正文、名单与适用性后生成。签到表支持1～30人；回避事项声明、保密承诺、廉洁承诺每份一人，须填写经人工复核的适用正文。
3. 下载可编辑DOCX。生成时冻结项目公开打印字段、人员快照、正文、表单编号和版本；本人签名、实际到场时间、签署日期均留空。生成不会自动判定到场或签署。
4. 线下签署后，在“分类附件与不可变版本”选择“人员签署件”，上传PDF、DOCX、PNG或JPG并封存。此类别强制受限范围。
5. 在对应打印稿点击“登记本表签署回传”，选择精确封存版本、实际签署人员与日期，填写核对说明并确认。只登记选中的原表人员，不能把部分回传自动视为全员签署。
6. 名单或打印基础变化、已有后续表单版本时，旧表提示需要复核；使用旧纸件回传须填写适用性说明。复制生成新版本保留旧稿和旧签署件，新版本不继承旧签署关联。
7. 错误回传可填写原因后作废，保留原件和关联历史，再登记更正记录。打印稿作废后不能新增回传，历史文件仍按权限可下载。

## 数据和权限

- 每包最多100名有效准备人员。修订人员、表单作废与回传作废使用版本校验和原因留痕；不删除已冻结的人员快照。
- 生成校验采购包、会前准备和所选人员版本；页面保留未保存正文，基础变化后要求明确复核更新，不静默覆盖编辑内容。生成和回传支持幂等重试。
- 同一原表、同一人员最多一个有效签署关联。作废关联保留历史，释放后允许更正；实际签署日期按上海日期校验，不接受未来日期或早于原表生成日期。
- 表单及回传件均绑定具体文件版本和实际SHA256哈希，下载时核对字节。生成文件不可通过通用附件新版本入口覆盖，须通过表单版本流程另行生成。
- 租户、项目范围、建档审批守卫、会前准备读写、人员保密及附件权限在服务端执行。通用附件列表和原始下载路线也执行人员保密检查，附件创建人或普通受限附件权限不能绕过。
- 工作区展示最近100份表单、200条回传记录；历史数据持久保留。现阶段没有面向大量历史记录的分页检索界面。
- 数据库事务失败可能留下未被数据库引用的对象存储文件，沿用现有附件存储策略；本轮不自动清理对象存储。

## 接口与实现

执行接口契约：[p2-forms-openapi.json](p2-forms-openapi.json)，从运行服务导出，包含50个操作、47条路径、87个引用模型。本轮新增9个操作，位于 `/api/v1/buyer/agency/execution/packages/{pkg}`：

| 方法及路径 | 用途 |
| --- | --- |
| GET /preparation-forms | 人员、冻结表单和回传工作区 |
| POST /preparation-people | 新增准备人员 |
| PUT /preparation-people/{id} | 版本控制的人员修订 |
| POST /preparation-forms | 人工复核后生成打印稿及后续版本 |
| POST /preparation-forms/{id}/void | 作废打印稿 |
| GET /preparation-forms/{id}/artifact | 下载原版本打印稿 |
| POST /preparation-forms/{id}/returns | 人工登记签署回传 |
| POST /preparation-returns/{id}/void | 作废回传关联 |
| GET /preparation-returns/{id}/artifact | 下载固定签署件 |

新增V273迁移保存人员、表单快照、回传及有效签署关联，已在独立库应用。服务见[AgencyPreparationFormsService.java](../../backend-java/src/main/java/com/procurement/agency/application/AgencyPreparationFormsService.java)，排版见[AgencyPreparationFormComposer.java](../../backend-java/src/main/java/com/procurement/agency/application/AgencyPreparationFormComposer.java)，界面见[会前表单面板](../../apps/tenant-portal/src/features/agency/agency-preparation-forms-panel.tsx)。
