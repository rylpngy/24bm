# P1 权限与验收映射

## 权限点

| 权限 | 用途 |
| --- | --- |
| buyer:agency:read | 查看授权采购包、项目标签及基础选项 |
| buyer:agency:manage | 建档、修订与成员维护，仍受包范围和阶段限制 |
| buyer:agency:submit | 提交与合法撤回建档及重要变更，不能代审批 |
| buyer:agency:configure | 修改公司编号格式和类别字典，接收容量告警 |
| buyer:agency:file:read | 查看授权附件版本，不自动取得下载权 |
| buyer:agency:file:manage | 创建文件与版本、上传、封存、取消未完成版本 |
| buyer:agency:file:download | 下载有权访问的已封存文件 |
| buyer:agency:file:confidential | 在采购包范围内访问受限附件；创建人也可访问自己的受限附件 |

既有buyer:*通配按底座约定覆盖这些点，但不能越租户、绕过档案状态或自审限制。VIEWER在没有其他范围授权时只有项目阅读资格，不能因拥有通用维护权限替代本包的写范围。部门及公司授权按底座数据范围与项目参与关系组合。

## 需求与证据

| 需求 | P1实际交付 | 验证 |
| --- | --- | --- |
| DEC-01、ARC-01～02、AT-01 | 洽谈建档、协议后补、审批前门禁 | HTTP草稿、提交、未发布流程回滚、readiness拒绝 |
| DEC-02、6.8、AT-02 | 公司年度四位流水、幂等、原号重提、容量警报 | 并发多包及同包、跨类别、公司年度隔离、9999、规则更新；跨月与年份格式另有策略单测，未做真实跨日时钟演练 |
| DEC-03、AT-03 | 稳定项目标签、多包独立对象、授权范围汇总 | 三包批量幂等，BigDecimal汇总1029.30核对，无重复计入 |
| DEC-04、6.5 | 单有效主负责人、协作职责与历史 | 数据库条件唯一索引、有效人员检查、只读和协作接口验收 |
| ARC-03、WFL-01、7.2 | 在审冻结、重要变更独立流程、版本快照 | 退回、撤回、再次提交、通过生效、原值保留、回调错版本和重复回调单测 |
| 5、SEC-01、AT-19 | 租户和包范围、文件范围与独立下载权限 | 跨租户、跨项目、成员职责、受限文件、独立下载拒绝、自审拒绝 |
| 6.7、SEC-02～03 | 不可覆盖附件、基础内容检查、大小限制、审计 | MinIO真实字节、哈希、旧版下载、EICAR/宏结构与路径检测、413超限、下载审计 |
| 21.2、AT-20的P1部分 | 幂等、乐观锁、编号事务与审批竞争一致性 | 异参同键拒绝、旧版409、审批与撤回竞争、失败回滚 |
| DEC-11～12、AT-22的一期入口部分 | 六方式可选、半流程模式；全流程禁用 | 六方式分别完成建档审批；不作为AT-07～13评审验收 |

完整采购文件版本、公告审批、AI检索、独立评分、报价、费用和正式档案导出不属于P1已交付内容。全部AT-19/20/22需在后续模块实现后再完成整体验收。
