# P4标后、收支、办公室与正式档案

2026年11月10日，一期半流程技术交付。此处办理线下事实与内部审批，不发起外部公告、消息、电子签署、银行支付或税务开票。

## 标后结果与文书

结果登记引用本任务已审核、当前有效的报告，确认对象来自真实人工推荐名单。采购人代表账号需具有冻结代表职责及确认权限；其他工作人员只能按单独登记权限录入真实有权书面决定，并保存主体、职责、权限范围、时间、理由及凭证。失败／终止作为独立有权决定登记，不伪造推荐或成交。已有审核中或对外办理文书时，不能直接更改结果以掩盖影响。

公告、通知书、合同草稿采用实际封存DOCX范本，保留范本原内容，附加受控项目、主体、金额及人工核对内容；合同还绑定本轮已审核采购文件，记录履行要求及响应承诺。其含义是可核对草稿，不代表自动完成合同条款审查或复杂Word模板字段替换。真实模板的排版、条款和签署验收单列。

文书独立Flowable审核使用 `agency_post_document`。公告审核后登记人工外部发布；通知书依次为生成、审核中、已审核、已签发、已送达；合同审核后登记双方实际签署版本与日期。实际办理须有接收主体、渠道、外部定位和凭证，后续时点不得早于前序。签署金额变化不能静默写入，应先有权处理对原结果的影响。服务费是否收齐不作为通知书发放门槛。

质疑、投诉等事项记录责任人、收到时间、处理期限、材料和状态。暂停、恢复、终止必须选择明确的有权控制动作及真实依据，另需控制权限；普通登记或关闭事项不自动改变控制状态。暂停／终止阻断后续文书生成、通过审核和对外办理；终止不得自行恢复。

## 收入成本及办公室

收费约定从立项档案冻结，人员核对实际触发节点、付款方／收款主体、税费口径、基数、固定金额或费率、折扣及规则版本后，形成待核算应收。系统最后统一四舍五入至两位小数，不预设法律收费表；真实Flowable `agency_finance_review` 独立核定后才进入确认应收。减免、增加应收同样经独立核定后生效。

实际到账、退款、开票及作废／红冲分别记录，开票不算到账。保留真实超收并单列待处理，不通过拒绝事实掩盖差额；退款不能超过净实收。实际凭证同类型不得重复计入，相同日期金额另有重复核对提示。金额采用BigDecimal，接口金额按字符串传输。

成本分专家费、餐费、工具材料、交通、场地及其他，支持本公司自定义类别的启用／停用与版本冲突校验，历史类别不删除、不改动核心类别含义。预算、申请、批准、实际发生、实际净已付和待付分别保存，支付登记须有真实发生及批准余额。专家费用关联本包实际冻结参与人员、服务和依据，单独授权；普通统计隐藏专家身份、支付对象和私有服务明细。专家费用应使用专家类别，通用财务凭证先提供脱敏版本。

办公室展示授权范围内的审批、用印、文书办理、费用和补档待办，不自动催收。所属项目每个采购包仅汇总一次，按币种分别统计。差额明确为应收与实际成本口径差额，不混称审计利润。XLSX导出包含授权包的负责人、参与人数、节点完成、逾期、节点修订口径、金额及财务基础；金额作为精确文本写入，不导出专家私有明细，也不自动计薪。

## 正式档案与完成状态

资料从立项开始关联项目；方式清单区分必需、条件适用和可选，缺件需责任人及期限，不适用需理由及真实依据，必需项例外另需权限。纸质位置、电子副本和签署状态分开记录；内部审核不被当作真实签署。

正式快照保存当时全部封存文件的版本、实际长度、SHA256、来源及签署信息，并保留清单、缺件、归档人／时间和用户按制度确认的年限。可先封存明确不完整的快照；必需及条件项未核对时不能标记档案完成。后续更正需权限和原因，只能追加新快照。

业务、档案、费用三状态独立。业务可在有权结果登记后办结并安排遗留事项，之后仍可收付款与补档；继续开展新的采购执行／评审须先受控恢复业务。费用结清需人工核对无未核定、未收、超收和待付余额，后续流水重新打开费用状态。新增资料或费用、标后变化使归档重新积累，旧快照保持不变。状态变更使用单独版本，不修改评审依赖的采购包内容版本。

单包和所属项目集合ZIP逐文件重新校验当前权限和实际字节。无权读取的响应、报告等不披露名称，不因归档权限而授予文件读取权；目录明确授权范围、被排除数量、原快照是否已存在后续变化及缺件说明。文件名规范化、路径分隔符／控制字符处理和不区分大小写的重名防护避免越界或覆盖，保留下载审计。单文件50MB、单次授权包150MB、单包1000版本、集合50包是本轮技术容量限制；超过时明确失败并要求分批，不返回部分成功包。保留年限必须按单位制度输入，系统不自动永久删除。
