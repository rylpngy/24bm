# P3第七项：综合评分受控汇总与复核

2026年11月9日。接续价格规则、价格计算和本人独立意见，实现综合评分的独立汇总：唯一计分来源、成员版本核对、明确舍入顺序、人工复核及不可覆盖历史。尚不形成确定排名、候选人推荐、有权结果确认或成交金额；未部署生产。

## 使用与范围

入口：“评审准备 → 独立评审任务 → 综合评分受控汇总”。仅综合评分方法展示。需要冻结的组织人员/组长职责、汇总读取/管理权限，并具备价格计算读取权限。普通评审人即使持通配权限，也不能越过冻结职责读取该工作区。价格比较、谈判价格规则、单一来源等不能冻结本综合评分汇总规则。

分别填写原文与系统汇总规则：规则版本、适用依据、原文定位、每个冻结评分项的唯一来源、总分保留位数和舍入方式。当前只支持等权原始分合计后加权、同分标记待人工处理，不支持去高低分、成员特殊权重、任意脚本或自动破同分。草稿可按版本维护；两侧差异、缺项、重复项、未知项或不匹配来源阻断冻结。

全部评分项必须恰好覆盖，且恰好一个价格项使用客观价格计算，编号与已冻结价格规则相同。其余项使用承担该项评分职责的全部冻结成员，不能挑选人员或剔除不利评分。权重沿用原轮次，精确合计100；分项/总分舍入组合导致满分不等于100时阻断，不自动裁剪。冻结快照绑定原评审轮次、定稿版本及价格规则指纹，冻结后不能覆盖；变更须按异常程序另行组织。

## 汇总闭环

1. 明确选择一份本任务已人工确认且仍有效的价格计算，不自动选择最新记录，也不允许借用其他任务的记录。复核其输入指纹、规则指纹和实际计算明细；失效价格须先重新复核，不能直接用于汇总。
2. 继承价格计算的对象范围和逐家排除依据，继续执行末阶段开放、相关本人意见全部提交、无待审更正、有效价格来源及对象数量门槛。不能从汇总入口绕过审查、缺失最后报价或异常门槛。
3. 成员项计算：`原始分精确合计 × 冻结权重 ÷（本项全部冻结职责成员数 × 满分）`。不先舍入平均值；仅在分项最后一次除法按该冻结评分项的位数/舍入方式处理。缺成员、重复成员、缺分值、超范围或提交版本指纹不一致时阻断，不补分、不推测意见。
4. 价格项直接读取所选价格计算的客观价格分，不再计入人工价格项分值，也不把价格分重复加权。人工价格项原提交保留，系统不修改或回填个人意见。
5. 分项最终结果精确相加，再按冻结的总分位数与舍入方式处理。预览展示分项值、原始分合计、精确分子/分母、成员数量、提交版本与SHA256，以及唯一价格快照。数值使用BigDecimal并按十进制字符串输出。
6. 人工核对后，服务端在采购包事务锁内重新计算，校验当前输入指纹及脱敏复核凭证的封存字节，保存不可覆盖的汇总快照。价格台账、成员意见、更正或项目有效状态变化，使旧确认失效；历史标记需重新复核，旧值保留。界面保留未提交的人工说明及所选价格版本。

汇总只返回聚合数值及提交版本指纹，不带出逐人分值列表或意见正文。新增汇总读取权限允许查看这些聚合明细；它不允许改写个人意见或代替成员再次提交。全部成员提交仍是共同门槛。

同分按最终舍入后的总分识别并显式标记待人工处理，保留冻结依据；对象保持源数据顺序，不生成名次、赢家或推荐标识。没有同分也不等于可以把独立汇总当作确定排名。历史显示最近30份，每任务最多保留100份；每次确认均有幂等保护和独立复核凭证。
