# P3第二项：本人独立意见、提交锁定与受控更正

日期：2026年11月9日。本轮接续[评审轮次与规则冻结](P3评审准备交付说明.md)，完成共享评审核心中的独立意见闭环。代码仍在24Bid隔离研发工作区，未部署生产。采购方式完整现场程序、报价、计算汇总和排名不属于本轮交付。

## 使用流程

进入采购包“采购执行工作台 → 评审准备”，在有效冻结轮次展开“独立评审任务”。

1. 有权的冻结组织人员或组长明确选择内部参与台账中的对象，引用精确封存的项目可见线下开启凭证，填写实际开启时间和核对说明，并明确确认。系统不从台账自动判断资格、有效响应或到场。
2. 系统按冻结账号及职责建立独立任务，资格审查、符合性审查及技术商务意见分别分配。组织人员、组长和通配管理员不会仅因管理权限获得他人的评分身份。
3. 评审人在“本人独立评审”填写分值或通过/不通过结论、资料位置或事实依据及本人意见。允许保存部分个人草稿，不从他人的评分、平均分或历史结论自动填充意见。
4. 完成本人全部对象及职责项后先保存，由本人复核并明确提交。提交后锁定本版；组织人员只查看完成状态，不读取个人分值和评语。
5. 更正由原提交人选择对象和项目、填写原因、引用封存依据，按已发布的“代理个人评审更正”Flowable流程申请。没有已发布流程时不能绕过审批，原提交保持锁定。
6. 独立审批人须同时满足流程任务办理、数据范围、更正审批权限及冻结的组织/组长职责。申请人不能自审，即使管理员或流程把其本人配置为办理人也不例外。
7. 审批通过后为原评审人生成下一版草稿，带入其本人上版意见，仅获批组合开放修改。由本人再次保存、复核和提交；原值、指纹及更正依据保留。
8. 驳回或本人撤回不解锁原提交；仅申请人可撤回自己的待审申请，保留流程及原因。

## 身份与保密

- 个人读写按当前登录账号定位任务，不接受客户端选择代评身份，没有按任意评委ID读取意见的入口。
- 账号须仍有效，并具备采购包读取范围、评审读取和保密权限；本人写意见另需独立评审权限。显式授予这些权限的项目只读成员可提交本人意见，无需取得项目管理权限。
- 组织权限不等于评分身份。进度仅返回姓名、版本及草稿/提交状态，不返回分值、评语或平均分。
- 未建立任务前，普通评审人入口不返回待选对象；任务引用组织人员明确确认的线下开启记录。本轮不导入或在线解封供应商响应材料。
- 个人草稿及历史意见只通过本人入口返回。通用业务事件只自动记录版本、状态和内容指纹，不附带完整个人意见。
- 更正流程快照保留原提交指纹、范围、原因及依据，不自动附带完整评分内容。申请人填写的说明仍会供有权审批人阅读。
- 账号停用、权限撤销立即阻断旧凭据或请求。账号重新启用后须重新登录；旧凭据不会自动恢复。

## 数据与状态

每个冻结轮次最多一个独立任务，明确1～30个对象；人员和规则上限沿用前轮，每人最多3000个对象与项目组合。建立时冻结对象名称、规则指纹、开启凭证版本及实际字节哈希、开启时间和说明。

个人版本为草稿或已提交。草稿允许缺项，已填写分值仍须在冻结范围内且最多6位小数；拒绝其他职责项、未知对象和重复组合。提交要求全部本人组合完成、必填依据和本人意见齐全，并明确确认。审查项不能携带分值，评分项不能冒充审查结论；零分不视为缺项。

保存、提交和申请使用版本校验及幂等键。并发相同提交只产生一个提交结果。页面发现版本变化时保留未保存内容并阻止覆盖；未保存编辑不能直接提交。

已提交内容没有普通修改入口。更正绑定当时个人版本、指纹、获批组合及依据，通过后新建本人版本。服务端逐项比较未获批组合，数值等价的小数表示除外，其分值、结论、依据和意见均不能更改，删除未获批组合也会被拒绝。

轮次作废、档案待审或基础变化时禁止继续写意见，已完成工作保留，在仍具备权限时可读本人历史。基础变化导致待审更正不能继续办理时，应由申请人撤回复核，不可后台改分。成员替换、完整暂停恢复及重新组织仍在后续范围。

## 接口与实现

新增V275迁移保存任务、个人版本和更正申请，已在独立库应用。更正复用现有统一Flowable运行时和回调，不另建审批引擎；流程定义页面增加了相应业务类型。

接口前缀：`/api/v1/buyer/agency/evaluation/packages/{pkg}`。本轮新增8个操作：

| 方法及路径 | 用途 |
| --- | --- |
| GET /rounds/{round}/assessment | 任务入口及组织人员可选对象 |
| POST /rounds/{round}/assessment | 确认开启记录后建立任务 |
| GET /sessions/{session}/mine | 本人职责、草稿、历史与申请 |
| PUT /sessions/{session}/mine | 按本人版本保存草稿 |
| POST /sessions/{session}/mine/submit | 本人确认提交并锁定 |
| GET /sessions/{session}/progress | 无意见值的完成进度 |
| POST /sessions/{session}/corrections | 本人申请Flowable限定范围更正 |
| POST /sessions/{session}/corrections/{id}/withdraw | 本人撤回待审申请 |

完整[P3接口契约](p3-assessment-openapi.json)从运行服务导出，共14个操作、11条路径、36个引用模型。实现见[个人评审服务](../../backend-java/src/main/java/com/procurement/agency/application/AgencyAssessmentService.java)、[独立意见及更正范围校验](../../backend-java/src/main/java/com/procurement/agency/application/AgencyAssessmentPolicy.java)、[更正回调](../../backend-java/src/main/java/com/procurement/agency/application/AgencyAssessmentCorrectionProjector.java)、[个人面板](../../apps/tenant-portal/src/features/agency/agency-assessment-panel.tsx)。
