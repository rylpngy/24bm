# P2下一项：参与台账批量导入

日期：2026年11月8日。本次在原隔离工作区补齐可选参与台账批量导入，延续[提醒与模板治理补充](P2补充交付说明.md)。批量导入只用于内部参与记录，不产生供应商准入、正式资格审查、有效投标家数或成交结论；未修改原24Bid工作区，未部署生产。

## 使用方式

进入已通过建档、没有待审重要变更的采购包。在“分类附件与不可变版本”上传并封存UTF-8 CSV或单工作表XLSX；来源须为项目可见资料，受限文件先形成适用的脱敏版本。

在“采购执行工作台 → 参与台账”展开“批量导入与来源预览”：

1. 下载CSV空白模板，填写数据后上传；信用代码和电话请保存为文本，防止电子表格软件丢失前导零或精度。
2. 选择精确封存文件版本生成预览。此操作不新增台账记录，展示每条数据、来源记录序号、错误和警告。
3. 有错误时修改来源文件并上传新版本，重新预览；错误不能通过确认或允许重复绕过。
4. 人工核对记录、来源、警告及内部用途后确认。如果确实需要新增可能重复的记录，还需单独确认重复提示。
5. 成功后整批追加；原记录及其版本保持不变。最近20个可访问批次可重新打开，已完成批次不再提供重复确认按钮。

支持列：供应商名称、统一社会信用代码、联系人、联系电话、记录来源、文件获取情况、响应递交情况、待核实事项、风险复核情况、备注。供应商名称必填；未填状态使用待核对/待复核，未填来源明确标识导入文件和记录序号，不虚构实际发放或资格结果。

文件获取状态支持待核对、已获取、不适用；递交状态支持待核对、已提交或已递交、已撤回；风险支持待核实或待复核、已核实或已复核、不适用。相应英文状态码也可使用。其他状态为错误，不把“准入批准”“资格合格”等转换成台账批准。

## 范围与数据保护

- 每个文件不超过2MB，每批最多200条非空数据记录。支持UTF-8 BOM、CSV引号/逗号/换行和Excel文本单元格；CSV记录序号包含表头，XLSX保留工作表行号。
- XLSX一次只接受一个有数据的工作表，不接受外部工作簿链接；公式单元格不计算，作为预览错误，纯公式行不会静默丢弃。CSV疑似公式前缀也列为错误。数字单元格提示核对前导零和精度，不承诺恢复已被Excel修改的数据。
- 未知或重复表头、异常引号、错误编码、超量格式行/列或超限数据拒绝处理。采用固定字段解析，不执行文件中的指令或脚本。
- 重复检查依据供应商名称或非空信用代码，忽略空白及大小写。只提示可能重复，不自动认定为同一法律主体；确认时重新检查预览后新增的台账记录。
- 预览和确认均校验采购包阶段、租户、参与台账权限、项目写范围及来源文件权限；只读人员可查看授权来源预览，不能发起或确认导入。确认必须由预览创建人完成。
- 每条新台账保留批次ID和来源记录序号；批次保留原文件版本、实际字节哈希、预览内容及最终记录ID。以后人工维护台账仍保留批次来源，不覆盖原文件。
- 确认在一个数据库事务内追加全部记录、关联来源、记录审计并写入批次结果。失败整批回滚，批次仍可重试；请求幂等、乐观版本和来源行唯一约束共同防止重复追加。

| 接口 | 行为 |
