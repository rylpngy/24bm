# P3受控推荐与评审报告

2026年11月10日，一期半流程技术交付。推荐、报告审核、实际签署与采购人结果确认分别办理。

推荐必须选择本轮当前有效的价格计算／综合汇总，或单一来源的唯一专业协商记录。原文规则与配置逐项一致，明确次序、推荐数量及同价同分处理。系统校验人工名单的有效范围与次序；数量不足、来源失效、待审更正或未处理异常均不能确认。同价同分仍待有权处理时不得确认确定次序；有处理凭证时保留实际依据。推荐快照不可覆盖，政策评审价和实际响应金额分列，不把评审折扣变成合同金额。

报告叙述可在草稿状态编辑，数字、对象和依据来自不可变推荐快照。生成真实DOCX并封存实际字节和SHA256；只允许按当前叙述版本提审。报告保留冻结人员、独立意见引用、源记录、计算／协商依据、异常和人工理由；历史意见明确保留版本，不重复计分。报告含独立意见，必须具备报告保密权限并符合冻结组织职责；有权独立审核人员另受项目范围约束。

内部审批使用真实Flowable `agency_evaluation_report`，通过前须有已发布定义。参与创建、叙述编辑、生成或提审的人员均保留为编制参与者，不能借另一人代提审后审批自己的报告；实际发起人可以撤回。审批冻结当前叙述、文件版本／哈希、推荐及评审指纹，来源变化后不能批准旧报告。生成、内部审核通过均不宣称已签署或采购人已经确认。
