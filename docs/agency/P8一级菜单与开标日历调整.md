# P8 一级菜单与开标日历调整

2026-11-10，根据本轮走查意见，将通用采购门户调整为招标代理业务工作台。各业务模块拥有独立的一级菜单和页面，不再在“招标代理”页面展开整套系统功能。

## 业务入口

一级入口为：首页看板、开标日历、项目库、招标文件库、模板库、公告管理、智能审批、项目执行、合同管理、费用管理、流程引擎、组织架构、团队与权限、编码规则、AI审查依据、审计日志。入口仍按现有权限控制。

项目库复用原代理采购包模型，支持项目经理创建项目、立项审核、项目资料及成员管理。所属项目继续支持多包关联；不将原通用采购的项目申报库混入代理项目库。已立项的详情只提供业务链接，不嵌入文件、执行、费用等整套工作区。

招标文件库与公告管理分别汇集授权项目的文件及不可变版本，可以进入项目编制、审核和下载。模板库独立检索公司及授权项目模板，可新建公司模板并送审。模板更新保留既有引用快照。二审、三审仍由流程引擎配置实际节点及办理人，本次不把所有企业的审批强制改成固定三级。

项目执行按公开招标、邀请招标、竞争性谈判、竞争性磋商、询价、单一来源组织项目列表；选中项目后办理执行计划、参与台账、开标安排、开评标、标后事项和归档。费用管理独立进入项目收支工作区。合同管理保留原合同台账、审批及履约能力。

移除工作台中的采购需求、物料目录、采购计划、企业商城、供应商库、询比、竞价、采购订单、收货验收及发票付款等通用采购入口。保留底层历史记录与原接口，不执行业务数据清理。

## 开标日历

日历读取招标文件公共发布要素中的“开启时间”和地点，显示月度总场次、安排天数、每日场次及所选日期项目。支持月份切换、今天定位、采购方式过滤及项目跳转。时间统一按北京时间展示，未登记有效开启时间的项目不计入场次，会前会议预订不冒充开标时间。

新增只读接口：

- `/api/v1/buyer/agency/workbench/calendar?month=YYYY-MM`
- `/api/v1/buyer/agency/workbench/documents?kind=purchase&page=1`
- `/api/v1/buyer/agency/workbench/templates?method=公开招标`

查询沿用租户、创建人、负责人、项目成员及部门数据范围；文件库另校验文件读取权限，原文下载仍通过原版本授权接口。公司未发布模板仅模板管理员可见。本次没有新增数据库迁移或改写审批/财务规则。
