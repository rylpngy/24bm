# P3第八项：评审异常登记、暂停与恢复条件

2026年11月9日。新增按评审轮次管理的异常台账和控制状态，接入材料、本人意见、最后报价、价格计算及受控汇总的服务端守卫。保留历史、逐项处理及独立恢复决定，不自动放宽人数/规则、替换成员或切换采购方式。未部署生产。

## 操作闭环

入口：“评审准备 → 对应冻结轮次 → 评审异常与暂停恢复”。可在尚未建立独立任务时使用，覆盖会前接收、正式开启和后续评审。无异常的既有轮次默认进行中、控制版本0，不因此失效原有计算记录。

异常目录包括成员缺席、回避、文件缺失、版本冲突、无效响应、对象数量不足、报价异常、意见不完整、网络中断、评审暂停、采购失败、终止、更正、另行组织及其他。每条记录保存真实发生时间、登记时间、有效且已获采购包授权的责任人及名称快照、影响范围、事实、封存脱敏依据及字节哈希、处理/恢复条件和登记人。

登记时明确选择：

- **仅登记**：本轮保持进行中，保留正常业务写入；未处理异常仍阻断价格计算结果和汇总，不自动忽略问题。
- **登记并暂停**：暂停本轮全部评审写入。影响范围文字用于记录事实，不用于自动推断局部放行；暂停范围明确为整个轮次。

处置时填写真实处理时间、处理凭证、说明，并人工核对条件。时间不得早于异常发生或晚于当前时间。结果为“本异常继续条件已满足”“需另行组织”或“需停止本轮”。原事实不能编辑/删除，处理结论不可覆盖；网络重试以幂等键返回同一结果。

**结案不自动恢复。** 需单独核对当前控制版本、全部异常指纹、实际授权依据及恢复条件，再执行恢复。所有异常必须已处理，且均为继续条件已满足；选择另行组织/停止的旧轮次不能恢复。原建档、重大变更、冻结规则、文件和人员基线仍须有效。恢复不代表更正已获批或审查已通过，原有更正授权、阶段、版本、来源和数量守卫继续执行。

支持依据未处理异常单独暂停，也支持明确停止本轮。停止后不可恢复，不再新建异常或进行评审写入；历史保留，原有未处理异常仍可追加处理结论。停止本轮不自动改变采购包业务、档案、费用状态，不自动终止整个采购项目或形成结果。

## 实际阻断与历史

暂停/停止在服务端执行，不依赖隐藏按钮，覆盖：

- 材料接收计划、接收登记、正式开启及建立独立任务。
- 本人意见保存/提交、阶段放行及受原更正流程控制的评审写入。
- 报价台账、最后报价发起/接收/确认、价格规则和计算、汇总规则和确认。
- 通用附件上传入口中的受控响应及最后报价副本：原始上传票据、上传和封存路径继续检查所属轮次状态（包括暂停前已签发票据的上传和登记），不能绕开专有页面。

历史读取及原有按职责开放的精确版本下载保留。原本人草稿、已提交意见、响应、报价和计算快照不删除；通用项目资料和脱敏处理凭证可按原权限维护，供异常处置使用。

每次登记、处置、暂停、恢复或停止均提升控制版本并追加控制历史，记录前后状态、异常指纹、依据版本与哈希、操作人及时间。该版本纳入价格输入指纹，继而传递到汇总。即使暂停后已恢复为进行中，暂停前的价格/汇总确认也不会自动重新有效，须重新生成预览并复核；旧结果仍保留。

## 权限和材料范围

异常明细仅冻结组织人员/组长可读，另需异常读取权限；登记/处置需异常管理权限；暂停、恢复、停止及另行组织/停止结论需轮次控制权限。责任人字段不自动授予管理权限。普通冻结成员只看到中性的控制状态、未处理数量和操作阻断提示，不看到异常事实、责任人、处理正文或控制表单。通用业务事件仅携带状态/版本，不复制异常明细。

当前只引用可共享的**脱敏**项目封存凭证，并校验实际字节；不提供原始敏感案据专柜或自动脱敏能力。不得将个人意见正文、未授权响应原文等作为普通项目附件误传。本轮的更正、回避、重新组织等是事项及处理依据记录，不代替原Flowable更正审批、冻结人员变更程序或实际有权决定。
