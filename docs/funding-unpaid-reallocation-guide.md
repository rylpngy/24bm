# 付款后未付资金责任调整

## 操作

1. 在已批准项目详情展开“资金分摊”，点击“调整未付额度”。需要项目和预算管理权限；仅适用于已有真实付款历史及专项分摊的项目。
2. 逐项填写当前资金来源的调整后责任金额。已付金额只读，调整后责任不得低于已付金额；所有来源合计必须保持当前年度责任总额不变。
3. 填写原因，提交到真实专项资金审批。发起人与办理人分离；批准前不改变资金占用，审批期间暂停项目专项付款、冲销、继续承接及采购执行归档。
4. 办理人核对前后金额、原已付归属和来源限额。审批时重新验证项目、资金版本和容量，依据变化不能直接批准；可驳回后重新申请。
5. 批准后追加不可变调整明细，不覆盖原分摊、原付款或承接快照；不切换当前资金计划版本，因此同年度原付款仍可按原来源正常冲销。已跨年冻结的付款仍须走专门更正审批。
6. 在“资金审批记录 → 未付额度调整 → 详情”查看调整前后责任及真实流程。执行归档包同时保留原方案、调整、付款和审批证据。

## 示例

项目 1200 元，资金 A/B 原分摊 700/500 元，已付 150/50 元。可经审批将当年责任调整为 650/550 元，相当于 A 的未付额度减少 50 元、B 增加 50 元。原已付 150/50 元、总责任 1200 元均不变，不产生退款或新的出款。

如曾跨年，调整合计只包含当前年度责任，历史已付基线不参与重分摊。再次跨年时按调整后的剩余责任承接，旧版本调整明细及历史实付继续留档。

## 明确边界

- 本轮只在当前项目版本已有的资金来源之间调整未付责任，不新增来源、不替换已付来源、不追溯补造旧付款分账。
- 跨部门、跨年度调整通过相应业务流程办理，不能在本表中任意切换；专项来源限额即使预算为 warning 模式也须核验。
- 未发生付款的项目继续使用原“编制分摊”；已付款项目不能覆盖或撤销原分摊。
- 撤回、驳回或批准失败不产生占用变化。重复提交同一请求返回原申请，不重复调整。
- 专项终止清算、已结项/清算后重开、部分金额更正和银行实际退款不属于本轮完成范围。
