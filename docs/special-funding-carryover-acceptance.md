# 专项资金跨年度承接验收与交付

日期：2026-10-27。业务提交 `221944ba49f49d0d8eea31559978a8710918e360`；兼容修正及固定构建提交 `f134e3b23f6b0d0fbe1582af404a1accf41dc970`。后续文档提交不改变业务产物。

本批 PR：[#144](https://github.com/rylpngy/24bid/pull/144)，以尚未合并的 #143 为基础，未更新原系统。

## 本批完成

- 项目承接页面逐项选择原来源对应的目标年度来源，服务端按原来源未付余额计算金额，不按名称猜测。
- 同部门、目标年度、已批准来源、数据范围、合并目标的额度合计和审批时二次核验。
- 原来源历史付款保留；审批通过后发布新的来源版本，仅承接未付责任，支持连续多次跨年。
- 统一项目跨年审批、发起人与审批人分离、撤回/驳回；资金台账引用该真实审批，不另行模拟流程。
- 当前版本付款来源校验、历史已付基线、在审付款/冲销/归档保护，原来源流水不可直接冲销或通过冻结更正入口绕过。
- 项目详情及专项资金台账中的承接明细、真实流程历史，采购执行 ZIP 中的来源版本、原承接记录和审批证据。
- 修复资金台账按来源查询时遗漏项目分摊/承接记录的问题；JSON 空行明细按空数组处理。
- 兼容旧版在审申请没有新增 UI 可用性字段的情况，不修改原快照；金额、来源和付款依据仍严格比对。
