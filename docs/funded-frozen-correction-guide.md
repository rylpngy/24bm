# 专项资金历史冻结付款更正

## 适用范围

已批准项目存在明确专项来源的原付款，并已跨年度承接到后续资金版本。对可核验的历史冻结付款进行整笔更正，经独立审批后冲回原来源，同时恢复当前承接年度的未付资金责任。不代替银行退款或财务总账调整。

## 办理步骤

1. 在发票详情的“跨年冻结付款更正”台账选择原付款，点击“申请更正”。
2. 填写更正凭据号、原因；逐个原资金来源明确选择当前年度回补来源。系统列出原年度、原来源、整笔归属金额及当前来源可用额度，不按名称自动匹配。
3. 回补来源必须是该项目当前版本中同部门、当前年度的已批准来源。可多对一，但按合计校验容量；缺少选择或额度不足不能提交。需要新来源时先走受控项目资金配置，不在更正中临时增加。
4. 由真实独立办理人审批。审批期间暂停该项目专项付款、直接冲销、继续承接和采购执行归档。审批时重新核对原付款、历史基线、当前来源及额度；依据变化须驳回重提。
5. 批准后保留原正向付款，追加原年度、原来源、原资金版本的精确反向归属；向当前资金版本追加等额责任回补记录。撤回、驳回或核验失败不产生冲销和回补。
6. 在更正详情查看原来源到当前来源的映射、金额及真实审批历史。后续实际付款按当前年度来源重新登记，不自动发起银行出款。
7. 采购执行归档包保留原付款、反向付款、专项分账、回补记录、原承接快照及审批证据，支持查明操作者和责任链。

## 示例与边界

1200 元项目先支付 200 元，跨年后支付 300 元，再次跨年后支付 400 元。更正原 200 元后，原年度净付归零，历史已付有效基线由 500 元变为 300 元，当年未付责任由 300 元恢复为 500 元；原两次承接快照中的 200/500 元基线不覆盖。重新支付 200 元后累计净付 900 元，结项释放剩余 300 元。

- 原付款不能缺失或猜测历史专项归属；不能通过普通冲销绕过历史冻结保护。
- 本功能不是付款后任意改分摊。整笔更正仅按真实原付款来源反向记录，并明确恢复当前年度责任。
- 已结项、已终止、已归档或已清算项目的更正重开、部分金额更正和专项终止清算仍暂缓，保留现有拦截。
- 当前年度、原资金版本和原实付基线不直接改写；有效责任由不可变增量计算。
- 保留原系统数据、认证和预算 warning 模式；专项来源额度仍需真实批准，warning 不豁免资金来源限额。
