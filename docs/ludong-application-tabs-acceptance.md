## 分步草稿保存补充

- 六个 TAB 均提供“保存草稿”。保存当前已填写的整份申报快照，不清空其他 TAB，成功后仍停留在当前页。
- 首次保存创建草稿编号，后续保存更新同一条草稿；允许缺少单位、经费、设备、商城选型或交付要求，预算允许暂为零。
- 已填写的目录关联仍校验租户归属；非法数字、负数不能保存。只有草稿、已驳回申报允许更新，不修改审批中的材料。
- 当前 TAB 随草稿一起保存。刷新或退出后，从项目列表点击该草稿“编辑”，恢复已保存字段和上次保存的 TAB。
- 显示保存时间；继续修改后提示尚未保存。浏览器刷新或关闭存在未保存修改时提供离开提醒。
- “检查并保存”仍校验完整必填项，完整后保存申报并回到列表；列表“提交”由后端再次校验，通过后才发起审批。草稿保存不生成流程任务。
- 接口：POST `/api/v1/buyer/ludong-poc/applications/drafts`；PUT `/api/v1/buyer/ludong-poc/applications/{id}/draft`。沿用现有表，不新增迁移。
