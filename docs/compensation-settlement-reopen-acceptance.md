# 补偿款清算重开验收记录

日期：2026-10-28。PR：[#151](https://github.com/rylpngy/24bid/pull/151)，基于 #149。操作说明见 [业务指南](compensation-settlement-reopen-guide.md)。

## 一、本批实际完成

含补偿款清算通过新协议、新供应商确认及独立内部审批重新核定。货款与补偿分别保留现金基数，支持补偿调减、取消到零和再次增加；各款项按年度及真实资金来源核验退款或补付，不能只登记互相抵消后的净差额。

取消已支付补偿时，既要求实际退款，也要求金额为零的结清/取消凭证。原付款、原清算、原审批和旧归档不覆盖，仅最新有效版本计入汇总；库存不会再次释放。

首次含补偿款的清算强制逐票货款归属。页面显示上次约定补偿及已付净额，默认带入原金额；历史归属不明等重开限制在已有记录时也显示原因。数据库 V256 追加前版及补偿独立归属校验，不改写旧迁移或旧业务记录。

| 第二版 | 600 | 0 | 当年原补偿来源退款60，补充零金额取消凭证 | 600 |
