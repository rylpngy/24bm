# 专项项目终止与未用责任释放

## 本轮范围

支持已批准、已有订单且全部履约和财务责任已核验结清的专项项目，通过独立项目终止审批结束剩余项目范围，按资金来源释放未用责任。原合同、订单、发票、付款、来源版本和历史承接快照不覆盖。

本轮不是专项订单退款/补付分账：尚有未收货、未验收、待退款、待补付、未结售后或发票差异时，继续拦截。专项订单解除及退款/补付来源分账、已结项重开、部分金额更正仍需后续实现，不能因本轮开放项目终止而绕过。

## 操作步骤

1. 完成原订单履约、发票核对、付款及合同归档，完成各分包结项；未采购范围按原流程终止。申请人须有项目管理和预算管理权限，并能查看对应资金来源。
2. 打开项目详情，展开“跨年度承接与终止清算”，点击“申请已有订单终止清算”。
3. 查看原责任年度、当前年度和逐来源清算依据：原资金责任、保留已付金额、预计释放金额。跨年项目另外显示历史年度已付，不将历史已付当作可释放额度。
4. 填写原因并提交真实项目审批；发起人与办理人分离。批准前资金占用不变，审批期间不能付款、冲销或调整专项责任。
5. 审批时重新核对履约、净付款、资金来源与版本。来源、额度版本或单据依据变化须驳回重提；撤回和驳回不释放额度。
6. 批准后项目终止，资金台账保留实际净付，仅释放未用责任。项目历史与资金审批记录均引用同一真实流程，不重复建立虚拟审批。
7. 查看项目审批详情或专项资金台账详情，核验每个来源“保留多少、释放多少”；下载审批过程中生成的采购执行归档包，追溯原实付、资金方案、终止依据及审批人。

## 示例

项目 1200 元，A/B 原资金责任为 700/500 元；已完成的采购实际净付 500/400 元。批准终止剩余范围后，A/B 分别保留净付 500/400 元，释放 200/100 元，合计释放 300 元。原 900 元现金流水不冲销，原分摊记录不重写，银行实际付款和会计记账不由本功能自动操作。

## 安全边界

- 不为缺少来源归属的历史付款补造分账；实际净付、部门预算口径、专项来源及项目金额须一致核验。
- 在审资金分摊、未付调整、冻结更正、未结束采购和混合项目归属均阻止办理。
- 只释放当前版本的未用责任；历史年度实付继续留在原年度、原来源，不自动扩大或挪用资金额度。
- 保留原系统数据、认证及预算 warning 模式。功能开发、本地验收、CI、合并和部署分别记录。
