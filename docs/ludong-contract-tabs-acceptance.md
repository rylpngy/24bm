# 采购合同分类展示验收

日期：2026-10-27

## 分类与边界

| TAB | 展示内容 |
| --- | --- |
| 基本信息 | 合同日期、付款与质保条款、关键信息、到期续签提醒 |
| 履约记录 | 履约事件时间线、事件登记 |
| 付款对账 | 合同付款对账、行项、付款计划与里程碑 |
| 合同变更 | 变更申请、变更历史及现有审批操作 |
| 智能审查 | 原有合同审查台账、上传原件、规则版本、甲乙方视角、原文定位、修改建议、人工确认历史与校对稿下载 |
| 审批记录 | 原合同审批流程状态、当前办理人、处理意见和完整历史 |
| 附件与签署 | 原合同附件上传下载、签署及核验能力 |

- 移除常驻审批面板和其他 TAB 的关键信息侧栏，合同基本信息内保留关键信息；其他分类使用完整内容宽度。
- 保留原台账的独立“智能审查”入口及深链接，不替代或删除原工作台。
- 内嵌审查模式不修改页面 URL，不自动选中或关联其他合同的审查材料。现有审查文件与正式合同仍是独立台账，页面明确提示，校对稿不自动覆盖正式合同。
- 分类首次访问才加载，随后隐藏但不卸载，切换保留履约、变更、付款计划及审查工作区中的未保存输入。离开合同详情再进入不承诺恢复未保存输入。
- 原有提交审批、审批处理、推进履约、续签、归档的接口及权限条件保持不变。
- 实现位于基础系统采购合同模块，鲁东大学入口复用，不向基础模块引入 POC 依赖。
