# 阶段四第一轮：财务协同深化

## 目标

本轮从采购方财务协同开始，把阶段三已经具备的订单、收货、发票和对账台账入口，推进成可核对的业务视图。第一优先级是三单匹配：订单、收货、发票。

## 本轮范围

- 采购方发票付款：在发票详情中展示三单匹配摘要，覆盖订单金额、收货状态、发票金额、差异金额、匹配结论和付款边界。
- 应付对账单台账：在台账列表和移动卡片中展示匹配结论，帮助采购方批量识别待收货核对、金额差异待处理和三单匹配通过的记录。
- 付款边界提示：当收货未完成、差异金额未处理或三单数据未同步时，页面只提示核对边界，不临时扩展保存能力。

## 暂不做

- 不新增 Java API，继续复用 `/api/v1/buyer/invoices` 和 `/api/v1/buyer/invoice-reconciliations` 已返回的数据。
- 不接真实支付、银企直连、税控开票或外部财务系统。
- 不做完整财务凭证、复杂对账单审批和付款批次管理。

## 后续方向
