# 第二批：SRM业务深化

基线为已发布PR127/main `0f62ee09ed8d24aa51e3b583a15ff1ebb8a8b2a1`。默认保留预算预警，原库及附件不替换。

## 整批范围

1. 资质变更由采购方采集变更依据和自定义字段，发起独立Flowable业务类型，支持可配置多节点、候选人校验、当前任务、历史及取消重发。旧直接复核不能绕过运行时。完成最后节点才更新采购方复核结果；保留原件、旧版及既有历史。
2. 到期及退回补件任务：采购方指定材料、原因、期限；供应商上传换证并关联补件回复；采购方走同一变更审批，通过后自动闭合补件，驳回返回补正。过期状态按日期显示，不自动封禁、退出或取消原订单。保留已有定时提醒并避免通知无关采购企业。
3. 供应商关系Excel模板、行级校验及失败明细；仅关联已存在公共供应商，默认待准入，不导入审核结果，不覆盖公共主档。核查物料和组织导入，补导入模板/错误反馈等已有操作缺口，不另造迁移平台。
4. 双端统一状态/办理按钮/历史入口，旧证照下载核验、补件反馈及加载失败/重复操作保护。集中测试必要风险，完成后统一回归和真实HTTP/浏览器。

## 数据与交付

新增表仅承载流程尝试、补件任务，既有历史不回填、不虚构通过记录；待复核旧数据可人工发起新流程。旧流程材料被替代后禁止批准，可由发起人或流程管理员取消并重新发起。

写入验收在独立副本和附件桶。通过CI后合并，固定构建先验证原备份副本迁移、原字段行摘要及原附件一致，再更新5173—5176/API8080。保留上一固定发布和备份，不清库、reset或repair。正式SSO、外部信用平台和容量验收继续暂缓。
