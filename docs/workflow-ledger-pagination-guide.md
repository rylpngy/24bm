# 全局审批台账分页使用说明

## 使用入口

采购方后台 → 审批中心。待办、已办、我发起的、全部实例四类台账均按当前账号权限展示，并显示符合条件的真实总数。

1. 选择台账，输入业务单号、流程实例编号或发起人名称，点击搜索或按回车。
2. 在列表底部选择每页10、20、50或100条，通过上一页、下一页浏览记录。默认20条。
3. 查看详情后返回台账，保留查询条件和页码。切换台账、搜索或更改每页条数时回到第一页。
4. 待办办理完成后刷新相关列表和详情；若最后一页已无记录，自动回到有效页。已结束实例、详情读取失败或任务不匹配时不展示办理按钮。
5. 加载失败显示错误与重试入口，不把旧缓存当作本次查询结果。

## 数据和权限边界

- 主台账不再调用最多返回200条的旧列表接口。新接口为 `GET /api/v1/buyer/workflow/instances/page`。
- `view` 为 `pending/processed/initiated/all`；`page` 从1开始；`pageSize` 为1—100；`keyword` 最多100字符。越界页返回空列表及真实总数，不伪造记录。
- 已办、我发起、全部实例先在数据库中按租户、数据范围、视图及搜索条件筛选，再计算总数和分页。已办按实例去重，同一人办理多次不增加实例总数。
- 待办依据真实Flowable任务和办理权限筛选，再按实例去重、排序、计数及分页。保留本人获授权的实际任务，不用其他人的活动节点替换。
- 旧数组接口保留兼容；供应商详情的历次准入/退出分页及其5000条保护边界不属于本次修改范围。
- 待办仍需检查完整活动任务集合。本次消除展示截断，不表示已完成客户正式生产容量验收。

## 发布约束

本批无数据库迁移、种子或历史数据修订。验收样本只允许写入隔离数据库；原系统数据库及附件桶不得替换为验收数据。新分页发布状态以PR和固定发布目录记录为准，不将预览环境当作正式已发布版本。
