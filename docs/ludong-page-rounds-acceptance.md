## 本次发现并修复

1. 通用审批“业务详情”丢失当前 `solution`，可能跳离 POC。新增通用链接构建方法，仅保留当前场景，不携带旧记录或旧工作台参数。
2. 付款批次及归档例外审批误将批次号作为发票号打开。改为进入付款批次工作台，支持对应深链接；返回发票台账清除工作台参数。
3. 付款批次执行明细跳回发票时丢失场景。改为保留当前场景。
4. 询比项目从带 `recordId` 的链接进入后，返回列表会被详情自动选中逻辑重新打开。返回及继续编辑时清除旧记录参数，保留 POC 场景。
5. POC 切换菜单时清除 `financeView`，避免旧工作台参数残留。
