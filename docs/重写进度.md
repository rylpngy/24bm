## 采购主流程端到端贯通

```
采购需求(创建→提交→审批)→ 询价 RFQ(创建→邀请)→ 比价(TanStack Table)→ 定标
  → 定标审批 → 自动生成订单 → 订单履约(发货)→ 收货 → 发票 → 三单匹配 → 付款 →(后置)合同
```
旁支:供应商 SRM 治理闭环(准入→绩效→生命周期标记→资质预警)。

## 引入的标准栈

pnpm/Turborepo · springdoc → orval(正向契约)· shadcn 风格组件库 · TanStack Query · TanStack Table · Zustand · React Hook Form + Zod · ArchUnit。

- 正向契约:后端 springdoc 是唯一事实源,前端 orval 自动派生 hooks。
- 架构护栏:ArchUnit(分层 + 模块边界冻结基线)+ 项目租户隔离架构测试,多次拦住越界。
- 修复 3 个 baseline 隐患:finance 红测试、Flyway V120 冲突、dev seed V100 排序。
