# 询比价定标页面分类展示验收

日期：2026-10-27

## 页面分类

| TAB | 展示内容 |
| --- | --- |
| 项目概览 | 流程阶段、采购清单、时间与报价数量、完整分项报价规则、延期设置及记录、草稿操作 |
| 供应商参与 | 受邀供应商、查看与报价进度、催标和开标入口、商机报名受理 |
| 报价与版本 | 当前报价摘要、历史版本、选定版本的分项明细及附件 |
| 技术比价 | 采购技术要求与供应商响应横向比较、技术偏离、比价表导出 |
| 比价定标 | 价格比较、预算参考、供应商历史绩效、加权评审、推荐定标、再次报价及终止操作 |
| 澄清公告 | 问题澄清、补遗及项目公告记录 |
| 审批与结果 | 定标审批状态、结果公告、定标结果及通知书 |

- 草稿默认进入项目概览，报价中默认供应商参与，已开标默认比价定标，定标审批中和已定标默认审批与结果。
- 页头保留项目名称、状态、预算和返回入口；其他内容按类别展示。
- 切换分类保留页面内未保存的草稿编辑、延期原因、规则值及选定报价版本，不新增自动保存能力。
- 无完整分项报价的项目显示汇总报价及相应空态；开标前继续封存报价，不因切换页面显示价格或技术响应。
- 复用基础系统询比价组件，不将基础模块反向依赖鲁东大学模块。
