# 分次开票业务闭环验收与交付状态

日期：2026-10-26。PR：[#141](https://github.com/rylpngy/24bid/pull/141)。

## 本批范围

本批完成供应商普通分次开票入口及其采购方付款、合同、项目归档链路，不将“跨年冻结支出更正”和“专项资金分账”记为已交付。系统原有预算预警模式不变。

| 业务环节 | 实现及核验结果 |
| --- | --- |
| 供应商开票 | 已足额验收订单按原物料行选择本次数量，自动累计金额，展示累计已开及剩余可开；零税率原样保存 |
| 余额及来源核验 | 超量、超额、重复行、外部订单行、历史明细不完整、错误供应商及不合理分币拆分均拒绝；末次开票覆盖剩余行 |
| 重复提交 | 相同提交编号及内容返回原发票；相同编号改内容拒绝；父订单行锁和唯一索引防止并发重复开票 |
| 采购方核对与付款 | 本票数量与本票金额核对，不误报与整单金额的差额；每张发票分别审批付款申请和付款批次，再登记实际付款流水 |
| 合同付款计划 | 跨发票累计核对整单实际付款及里程碑分配；未达到条件的额度仍拦截，失败事务回滚，不伪造付款 |
| 合同及项目归档 | 仅当累计足额开票、逐票付款闭合、履约及审批完整后归档合同、采购执行、分包和项目；实际下载项目 ZIP |
| 多发票清算 | 真实开票产生两张发票后，第一张退款、第二张补付；整体净额已平仍须完成逐票凭证核验 |

本功能为供应商发票登记与业务核验，不包含税控发票开具、自动红冲或真实银行划款。订单尚未足额验收时不开放分次开票，不以本批功能代替预付款等其他业务模式。
