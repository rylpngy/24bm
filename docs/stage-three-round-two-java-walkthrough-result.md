## 未收口边界

- 平台公告编辑/撤回仍是前端生命周期入口，后续需要 Java API 承接真实状态变化。
- 租户功能开关详情仍以说明和只读核对为主，后续需要明确哪些开关允许平台运营修改。
- 供应商档案维护入口尚未完成 Java 持久化闭环，后续应补企业档案、联系人、授权品类和资质附件的保存接口。
- 第二轮详情、筛选、动作表单已完成页面级 Java 联调复核，但仍需要在后续 P1 中补真实编辑保存和刷新回显闭环。
