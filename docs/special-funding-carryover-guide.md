# 专项资金跨年度承接

## 操作步骤

1. 在“预算管理 → 专项资金”新增目标年度的资金来源，提交额度申请，由独立办理人批准。系统不自动扩大年度额度，也不按名称猜测来源。
2. 打开已批准项目详情，展开“跨年度承接与终止清算”，点击“申请跨年度承接”。
3. 填写目标年度、申请原因，为每个尚有未付余额的原专项来源明确选择目标来源。目标来源须为同部门、目标年度且已批准的资金；每项承接金额由原来源的剩余责任计算，不能手工扩大。
4. 多个原来源可以承接到同一目标来源，系统按合计金额核验目标可用额度。缺少映射、来源重复、年度错误、权限不足或额度不足时不能办理。
5. 提交后由真实独立审批人审核。原年度资金归属在批准前不改变；审批期间暂停该项目的专项付款/冲销及采购执行归档，防止审批依据变化。
6. 批准后，项目的当前资金版本转到目标年度，只承接未付责任；历史已付继续留在原年度、原来源和原流水。付款登记只能选择当前版本中的来源。
7. 历次承接可在项目台账、专项资金审批记录和流程详情查看。详情显示原来源、本版本已付、目标来源和承接金额。采购执行档案包含原承接记录、真实审批历史及资金来源流水。

## 示例

项目批准金额 1200 元，原来源分摊 A 700 元、B 500 元。已实际支付 A 150 元、B 50 元后，下一年度只承接 A 的 550 元和 B 的 450 元，原来源保留已付 200 元。

下一年度再支付 300 元后，如再次跨年，只承接当时剩余的 700 元；前两年度累计已付 500 元不重写。项目最终净付 900 元并结项时，释放未使用的 300 元，各年度、各来源实际付款仍可追溯。

预算责任年度与银行出款日期、会计记账年度不是同一概念，本功能不代替银行支付或财务总账。

## 业务边界

- 继续使用统一项目跨年审批，不额外模拟一条审批。资金台账中的跨年记录是该真实审批产生的来源版本证据。
- 无专项资金的项目沿用既有承接，不要求额外填写资金映射；原项目、需求、订单日期及年度额度均不覆盖。
- 不追溯补造历史付款归属。专项来源、历史净付、项目金额和当前版本必须能一致核验，才能承接。
- 撤回、驳回或批准时核验失败，均不切换资金版本、不释放或增加资金责任。
- 已冻结的专项资金历史付款暂不支持更正；普通直接冲销及冻结更正入口均受保护。付款后重分摊、专项项目终止清算和结项后重开仍未开放。
- 当前资金责任已全部支付时，不再办理无未付责任的专项跨年；原有资金与审批记录保留。
- 本批不更改原系统预算 warning 模式、认证配置或原始数据。
