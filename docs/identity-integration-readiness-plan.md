# 第三批：统一身份接入准备

基于PR128/main，继续正式对接与生产落地计划，但只交付不依赖客户环境的能力。

1. 统一身份账号映射：可信issuer及签名sub显式绑定本地采购方成员，权限仍从本地角色/数据范围读取，禁止令牌自带角色扩大权限。
2. 启停、理由、版本防覆盖、审计及真实分页搜索；停用即时拒绝，恢复要求新令牌，不删除历史业务数据。
3. 团队与权限新增统一身份页面，展示配置状态、待办接入事项和账号管理；不通过配置存在就声称联调成功。
4. 映射严格模式显式启用；原系统保留原登录与配置，新增表为空，不自动关联旧账号，不切prod。
5. PostgreSQL及真实RSA/JWKS/HTTP、本地浏览器、CI、固定构建备份副本迁移、PR合并及原数据保留发布。

客户SSO的登录协议/字段确认、HR事件同步、供应链/财务/支付/模型真实接口、客户规模容量及安全测评仍待客户条件；本轮不是这些外部工作的替代验收。现有恢复/容量工具保留，不再重复建设。开发过程中发现其他接口缺口先记录，不临时扩张对接范围。
