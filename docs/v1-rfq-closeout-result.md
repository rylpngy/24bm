## 重跑

设置 `ACCEPTANCE_RELEASE_DIR` 指向含 `runtime.json` 和 `backend.jar` 的本地发布目录，并设置 `ACCEPTANCE_LOCAL_WRITES=1`，运行：

```bash
python3 scripts/v1-rfq-isolated-acceptance.py
```

工具依赖当前Mac Java21、Maven缓存中的Spring加密库、Docker中的 `procurement-saas-postgres`、已构建采购方dist，以及有效MinIO配置。运行配置可能包含密钥，不提交、不输出。每次新建数据库及附件桶；清理需另行确认。前端构建须先执行 `pnpm --filter @24bid/tenant-portal run build:preview`。
