# 供应商退出清理范围扩展

## 本轮边界

在PR115的角色权限提交上单独建立`codex/srm-exit-clearance`分支。PR115尚未合并，不将其描述为已发布。原5173/8080与原库保持不动。

复用现有合同、商城售后、订单、发票及付款流水，不另造财务台账。合同以未归档为待清理项，售后以非已完成/已拒绝为待处理项。订单开票覆盖不足需先核对；已付款或部分付款但缺少金额流水的历史记录不能视为余额为零。

返回未归档合同、未完成售后、开票不足订单、付款待核对数量及可核实发票余额，保留旧字段。可核实余额不包含未知项，不等同于供应商总应付。

提交退出与流程最终通过均重新核查，页面只消费服务端判定，不以隐藏按钮代替后端校验。明细沿用现有权限范围，无法查看时指明处理岗位，不能泄露越权业务明细。

不包含外部财务对账、自动核销、合同终止新流程或历史付款补造。

## 执行与验收

1. 后端：先补新风险及跨租户测试，再实现统计与提交/终审阻断。
2. 前端：扩展核查结果、合同明细和处理入口；旧响应、缺失字段、加载失败均不放行。
3. 集成：隔离数据库测试、前端测试/类型/构建、真实HTTP及桌面/移动浏览器检查。
4. 审查：独立审查边界与权限；更新实际完成及未完成项，不将新增核查等同全部财务闭环。
