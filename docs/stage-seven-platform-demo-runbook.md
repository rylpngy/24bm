# 阶段七平台运营端现场演示脚本

## 演示定位

平台运营端演示顺序为：平台看板 → 租户列表 → 企业审核 → 平台公告。

这条路径只讲平台方提供 SaaS 运营底座，不直接参与采购业务决策。现场不要把平台端讲成采购业务处理中心；平台方负责租户、企业准入、公告、套餐和功能开关，采购需求、定标、收货、发票付款仍由采购方和供应商协同完成。

## 演示前准备

1. 打开 `http://localhost:3000/?role=platform&module=overview`。
2. 确认顶部数据源显示 Java 模式，页面没有加载失败。
3. 确认左侧或顶部角色菜单处于平台运营端。
4. 准备好备用验收命令：
   - `npm test -- scripts/stage-seven-platform-demo-path-ui.test.ts`
   - `npm run java:smoke`

## 逐页讲解

### 1. 平台看板

先讲平台方视角：平台方看到采购租户、公共供应商、待审核企业和公告数量。这里的重点是平台运营概览，而不是采购执行细节。

可讲口径：
- 平台方提供账号、租户、套餐、权限、审计和公告能力。
- 平台公共供应商企业档案是公共身份层，不等同于采购方私域供应商库。
- 平台运营摘要用于判断下一步应该去租户配置、企业审核还是公告维护。

### 2. 租户列表

点击平台运营演示路径里的“租户列表”。讲租户状态、套餐、用户容量和询价功能开关。

可讲口径：
- 租户状态用于控制采购企业是否可继续使用系统。
- 套餐和功能开关决定采购方可使用哪些模块，例如询价比价。
- 平台能调整配置，但不进入采购方的定标、收货和付款决策。

### 3. 企业审核

点击“企业审核”。讲企业入驻资料、资料确认、风险确认和审核结论。

可讲口径：
- 平台审核的是企业身份、资料完整度和基础风险。
- 供应商进入平台公共库后，还需要采购方建立私域合作关系。
- 审核通过或驳回是准入动作，不代表采购方已经选择该企业合作。

### 4. 平台公告

点击“平台公告”。讲公告发布、编辑、撤回和站内通知触达。

可讲口径：
- 公告用于平台运营通知，例如维护提醒、版本更新、规则说明。
- 公告生命周期包括发布、编辑和撤回。
- 公告不会改变采购方业务单据、供应商报价或财务状态。

## 验收口径

本轮可以声明：
- 平台运营端已有 4 页轻量演示路径。
- 演示者可以从平台看板按顺序进入租户列表、企业审核和平台公告。
- 每页都有平台运营边界说明，避免误讲成采购业务处理。

本轮暂不声明：
- 平台套餐计费、用量统计和运营 BI 已完成。
- 公共供应商市场、供应商推荐和风险预警已完成。
- 平台端具备生产级运营后台的全部配置能力。

## 失败兜底

如果页面无法访问，先检查 `curl -I http://localhost:3000/` 和 Java 健康接口。

如果平台数据为空，可以先讲页面结构和边界，再用 `npm run java:smoke` 验证 Java 后端仍能加载平台 workspace、租户、公共供应商和企业审核数据。
