# 项目库与采购执行收口验收说明

日期：2026-10-25。代码基线：main `19ac64ce6175c97908ca0f99556698f41940f06e`。

## 本批交付范围

1. 未下发采购的分包需求可以重新编制，在审需求调用 Flowable 真实撤回，只有原发起人可撤回；修改后必须重新审批，历史审批不删除、不冒充本次批准。
2. 未采购或已失败且无订单的分包、项目可受控终止，取消需求并释放实际预算占用，保留原需求、执行、节点历史、处理前物料快照和审计记录。有订单或仍在采购的范围禁止直接终止。
3. 六个实际业务节点展示完成情况，支持计划日期、先后顺序校验、逾期识别和服务端分页调整台账；处理人展示真实姓名，原始记录可展开。
4. 已结项、已终止项目可下载整项目 ZIP，含项目定义、实际流程与调整历史、项目和变更原件及有效分包原始 ZIP、附件台账和 SHA256 校验清单。终止项目明确标记终止，不冒称完成履约。

## 已执行的功能验收

隔离数据库实际 HTTP 验收覆盖十组业务检查，包括真实在审撤回及非发起人回滚、独立重新审批、超过十条调整历史的第二页、无订单终止、订单阻止终止，以及询比、招标、失败重采三个包的完整履约和归档。三包有效需求预算合计3600元，净付款登记2700元，结算占用释放900元，根项目汇总未重复计算。

浏览器验收包含真实按钮操作：计划保存及逾期、重编后需求历史说明、终止及记录详情、在审项目撤回终止和 ZIP 下载；桌面1440及手机390宽度检查无整页横向溢出。前端全量651项测试及七个工作包类型检查通过。后端专项覆盖角色、租户、数据范围、版本冲突、流程在审冻结、分包量额、计划顺序、终止后的附件保护及并发审批/重编；并发控制不再以租户行锁阻塞工作流和审计外键写入。

最终合并、完整云端 CI、固定构建重复验收及原系统发布信息以发布目录 `RESTORATION.md`、CI 回执和构建哈希为准，不能以本文代替尚未执行的发布结果。

## 边界

本批不是银行真实支付、质量自动验收、独立终止审批或有订单清算。整项目包是重新核验来源后按需汇总，原分包归档仍原样保留，不宣称新增永久存储的不可变根档案。超100MB、1000个公共原件或1000条调整记录时明确提示按分包/分页处理，不静默缺失。

商城/竞价分包贯通、跨年度结转、有订单终止清算、专项资金独立账和客户环境接口仍列为后续事项，见 `project-execution-remaining-plan.md`；不能把本批写成全部剩余功能清零。
