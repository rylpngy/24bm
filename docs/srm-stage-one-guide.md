# SRM第一阶段操作与验收说明

## 入口与权限

采购方从“供应商库”进入档案、寻源、邀请、准入、资质、绩效及考核模板；供应商在供应商门户处理合作邀请、资质及整改反馈。采购方具有供应商读取权限可查台账，维护权限可配置模板、发起邀请和考核；审批仍由流程配置中的实际办理人执行。仅有读取权限不能通过页面按钮维护数据。

## 建立合作与准入

采购方在邀请管理选择平台供应商并填写对外邀请说明，受邀企业有相应读写权限的在职人员收到站内通知，可接受或拒绝。接受只进入“待准入”，仍需采购方核验资质并提交准入流程。采购方可撤回待回复邀请，不能代平台供应商接受；线下登记不是已发送通知。

## 资质与退出

供应商上传资质原件，采购方可认证下载及核验；换证按现有变更复核流程处理，历史材料保留。资质台账可按到期情况筛选。退出须通过流程，并核查未结订单、合同、售后及财务事项；异常不能通过前端操作绕过。退出和黑名单不删除历史记录。

## 考核模板、任务与整改

1. 在考核模板创建四维权重，质量、交付、价格、服务各0至100，合计100；零权重允许。
2. 修改时创建新版本，不覆盖旧版。停用后不能用于新的考核或任务；已有任务仍按分派时的版本办理。
3. 直接考核或分派任务时选择模板，未选择则沿用默认35/30/20/15。评分记录保存当时模板及权重，不随后续模板变更重算。
4. 周期支持年度、季度、月份。履约参考按北京时间的收货登记时间统计，不等于实际签收时间；无样本保持空值。人工确认后可回填质量/交付参考，价格和服务由人工评分。
5. 同期看板只比较相同周期。零分参与统计，未考核不参与均分或排名。切换录入周期会清空当前草稿，避免沿用旧值。
6. 指派任务由指定考核人办理；需要整改时，供应商提交反馈和本轮材料，采购方退回或复核关闭。历史意见、材料和审批/处理记录保留。评分及建议不会自动调级或拉黑。

## 台账导出

统一导出入口提供档案、准入、资质、同期绩效、整改、退出六类XLSX。同期绩效需选择有效周期；准入和退出额外需要流程读取权限，仅导出可见范围的最新审批元数据，不把最新实例台账称为完整历史档案。空结果仍含表头，超过5,000行明确拒绝而不截断。文件不包含银行账号、原始附件内容或动态审批表单全文。

## 本阶段验收场景

- 新邀请、接受、拒绝、撤回和线下记录，核对通知接收人及重复办理限制。
- 模板第一版考核后发布第二版，核对旧考核不变；旧版分派任务在模板停用后仍可办理。
- 跨采购企业读取、修改、导出应受权限限制；个人/部门范围只包含对应可见业务数据。
- 六种文件可下载并打开；异常、空结果和无权限不能显示为成功。
- 既有准入、换证、整改、退出相关回归通过后，备份原库及附件，在副本验证迁移，再发布固定版本并核对原数据。

外部信用平台、短信邮件、自动拉黑/调级、供应商自助退出、实际签收时间采集及统一身份账号全生命周期同步不在本阶段范围。
