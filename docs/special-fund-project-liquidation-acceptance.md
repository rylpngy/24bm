本批完成项目级终止：原订单履约、发票、付款和各分包已核验结清后，通过独立项目终止审批释放未用专项责任，保留原净付、原来源和版本。不是专项订单退款/补付分账，不能将尚未结清的订单直接终止。

- 真实项目审批与资金台账共用一个流程；发起人与办理人分离，申请人还须有预算管理权限及来源数据范围。

- 申请页、项目历史及资金台账详情显示每个来源保留/释放金额；审批回调自动生成当前采购执行归档，含原现金、来源及真实审批人证据。
