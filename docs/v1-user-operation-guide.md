# 通用版V1操作与交付说明

适用范围：原系统通用采购底座，非鲁东专属POC。这里只说明本轮核验的站内流程。

## 入口与岗位

本地采购方5173、平台5174、供应商5175、商城5176。生产域名及账号由部署管理员提供，本说明不存放真实密码。
平台管理员负责租户与企业；采购管理员负责目录、供应商准入、采购与流程配置；审批人从待办办理；供应商管理商品、报价与履约。正式使用须按岗位授权，不能全部共用管理员。

## 商城直采

1. 采购方先维护物料分类，将供应商纳入私域并完成准入。资质无效或缺失时先补齐，不绕过准入。
2. 供应商在“商城货架→商品中心”维护商品、规格、物料、价格、阶梯价、库存与交付周期，上传图片，提交审核。
3. 采购方核对商品、参数和价格后审核上架。调价等影响采购依据的变更须重新审核。
4. 企业管理员维护直采限额、分类范围与收货地址要求。没有权限、超限、失效商品不可直接下单。
5. 采购人在商城搜索/分类中选商品，查看详情和同目录比价，加入购物车，确认数量、地址与备注后提交。
6. 系统重算价格、库存及限额，按供应商形成订单；重复提交不得重复下单。此处是站内直采控制，不宣称每笔商城订单均经过自定义审批流。
7. 供应商确认并发货，采购方验收；需要维修等售后时提交申请，供应商处理并提供凭据，采购方确认结果。
8. 需要关联合同时建立合同草案并审批；供应商登记发票，采购方核对匹配并办理付款申请、批次审批和实际付款凭据登记，符合条件后归档。

实际银行付款、税控开票、京东/西域实时价格库存及外部下单，仍需正式对接；系统付款登记不是银行划款。

## 招标采购内部管理

1. 建立项目与采购包，选择采购方式，编制招标文件与时间安排，上传附件。采购文件审查的组织制度、人员及结论须按企业制度落实，现有资格预审不能替代采购需求/文件审查。
2. 邀请招标选择已准入供应商；按规则开启资格预审，供应商提交声明，采购方审核后领取文件。
3. 供应商提交投标，截止和开标时间之前采购方不能读取密封报价正文，不得以演示需要提前解封。
4. 达到时间后开标，核验有效性，组建评委并逐项评分；未完成有效评分时不得定标。澄清及二次报价记录留存。
5. 按评审结果定标，查看公告和通知，填写预计到货日期转执行订单。重复转执行关联同一订单，不重复生成。
6. 合同、发货、验收、发票付款和项目结项归档沿用通用履约能力；流标与重新组织应保留原记录。
7. 可从项目等关联入口直接打开指定招标详情，返回台账时清除记录参数，保留其他页面上下文。

本轮短周期单供应商招标是企业内部技术验收，不是政府采购法定供应商数量、期限、CA签名或第三方电子交易平台的合规证明。通用需求审查、任意评分规则配置等未被本轮样本证明全部完成。

## 常见处理

- 主按钮显示“处理中”时不能再次提交；失败后按实际提示处理，避免反复点击。
- 列表支持搜索、筛选和分页；手机宽度下部分表格需要在表格内部横向滚动，不应导致整页横向溢出。
- 无权或不存在的招标链接会显示提示，不会默默显示其他项目。
- 金额、数量、审批或附件不满足归档条件时先处理阻塞项，不修改原历史来强行归档。
- 历史已归档材料是当时快照，不应随后续变更覆盖。

## 发布与运行边界

本地发布使用固定构建目录、禁用种子、保留旧版本和数据库/附件备份。后台JAR本轮未修改，复用经过隔离HTTP及恢复验证的同一文件。
PR、合并、部署与生产验收分别记录。正式上线还需真实身份认证、密钥和演示账号治理、值班告警、容量目标、第三方接口及客户验收签认；不以本地页面可访问代替这些条件。
