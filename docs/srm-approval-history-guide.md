# 供应商历次审批追溯

## 操作入口

供应商库进入供应商详情，展开顶部“审批信息”，选择“准入审批”或“退出审批”。默认每页10条，显示实际可见总数及序号，按发起时间倒序排列。同一供应商驳回重提、再次准入及退出记录各自保留，不以最新一次覆盖旧记录。

每行“详情”打开对应实例的只读详情；包含当时流程版本、自定义表单、业务快照、办理记录、当前办理状态和关联附件入口。通过“返回审批列表”回到原页；切换供应商或审批类型重置选择，避免混看记录。历史查看不执行审批、不修改业务状态。

供应商库顶部导出类型新增“准入审批历史”和“退出审批历史”，原六类台账保持不变。历史XLSX每个节点事件一行，含实例、版本、发起/完成信息、节点、操作、办理人、时间和意见。没有事件的实例仍保留一行，不静默丢失。导出使用安全文本单元格。

## 权限和边界

- 页面仅向有流程读取权限的用户展示；后端按租户及当前数据范围筛选后分页，其他租户无法取得记录或详情。
- 导出同时要求供应商与流程读取权限，复用工作流稳定应用投影，不跨模块直接访问私有Mapper或API DTO。
- 单一业务最多5000实例，超限明确报错；单个导出最多5000行，节点行也计入，不静默截断。
- 历史导出不含原件字节和动态表单全文，不作为完整归档包。既有关系状态单独标为“当前关系状态”，不会冒充当时业务状态。
- 既有“准入台账”“退出台账”仍是最新实例摘要，选择新增的历史导出才能取得历次记录。
