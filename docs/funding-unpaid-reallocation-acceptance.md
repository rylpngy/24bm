# 付款后未付资金责任调整验收与交付

日期：2026-10-27。业务及固定构建提交：`542bc36f364c522f8633da98b130baa4d71fb846`。文档提交不改变业务产物。

PR：[#146](https://github.com/rylpngy/24bid/pull/146)，基于尚未合并的 #145。

## 本批完成

- 付款后可在项目当前版本既有资金来源间调整未付责任；总额不变、逐项不低于已付金额，校验同部门、当前年度、已批准来源及容量。
- 复用真实独立专项资金审批，支持幂等提交、撤回、驳回、审批时二次核验。审批期间保护付款、冲销、承接及执行归档。
- 追加不可变前后金额记录，不替换原资金计划，不移动或重写已付归属；调整后可正常付款及按原来源冲销同年度现金，跨年历史冻结保护保留。
- 项目详情新增“调整未付额度”，历史显示前后责任、原已付及真实流程；归档补齐调整和审批人证据，空新字段不影响旧档案快照。
- 数据库延迟约束防止已批准但缺少完整明细、总额不守恒、错计划/错审批人、错误业务类型或超出资金容量。
