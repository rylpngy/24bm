# 招标评分权重配置与验收

日期：2026-10-31。范围：通用底座招标模块，采购方与供应商共用同一后端规则。

## 使用方式

1. 在招标项目选择“综合评分法”，保存草稿后进入详情“评审规则”。
2. 配置技术、商务、价格三个权重，每项0至100，最多两位小数，合计100%。填写编制或调整依据后保存。
3. 每次保存生成新版本，保留原权重、修改人、时间与依据。旧页面不能覆盖其他人已保存的新版本。
4. 确认规则后提交采购文件审查。审查快照包含本次规则版本与权重；通过后调整权重，旧审查失效，必须重新审查后发布。
5. 审查中及发布后规则只读，不能在得知投标或评分结果后改权重。既有分数不会被后改规则重新解释。
6. 供应商领取招标文件后可以查看同一发布规则，不获得内部规则调整记录；未领取不能读取。
7. 评委技术分和商务分仍各按百分制填写，系统取均分；价格分按最低有效报价/本供应商有效报价×100折算。综合分按项目权重计算，汇总排序使用该综合分。二次报价仍采用已答复的有效修订价。
8. “最低评标价法”按有效报价升序排序，不使用综合权重；界面不会提供无效的权重编辑。

## 历史及重招

- 未配置的历史项目继续采用原50/20/30规则，不回写历史分数或补造配置记录。
- 未发布的旧文件审查未包含评分规则快照时，需要重新送审；已发布项目不倒补审批。
- 流标重新组织时，将原自定义权重复制为新项目的第1版并保留来源依据，不复制旧评分、投标或已通过审批；新项目仍须重新审查和设定时间。
